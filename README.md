# Haber Magazin

Basit, duyarlı ve erişilebilir bir WordPress haber/magazin teması.

## Kurulum

1. Tema klasörünü `wp-content/themes/haber-magazin` dizinine yükleyin.
2. WordPress yönetim panelinde **Görünüm → Temalar** bölümünden **Haber Magazin** temasını etkinleştirin.
3. **Görünüm → Menüler** bölümünden menünüzü oluşturup **Ana Menü** konumuna atayın. Menü atanmamışsa sayfalar otomatik olarak gösterilir.
4. Site başlığını, sloganını ve isterseniz özel logonuzu **Görünüm → Özelleştir** bölümünden düzenleyin.

Tema; yazılar, sayfalar, arşivler, arama sonuçları ve bulunamayan sayfalar için temel şablonlar içerir. Klavye ile gezilebilir bağlantılar, görünür odak göstergeleri, atlama bağlantısı ve semantik sayfa yapısı erişilebilirlik için yerleşik olarak sunulur.
